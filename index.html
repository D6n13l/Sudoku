Tastatur: Auf dem Handy öffnet das Antippen eines Felds die Zahlentastatur. 1–9 setzt eine Zahl, N schaltet Notizen um, Rücktaste löscht, Pfeiltasten bewegen, Strg+Z macht rückgängig, H gibt einen Tipp.

Die Vorgaben liegen punktsymmetrisch, so wie in den Heften des japanischen Verlags Nikoli, von dem der Name stammt. 数独 (sūdoku) kürzt 数字は独身に限る ab, wörtlich etwa „Die Ziffern müssen Single bleiben“.
